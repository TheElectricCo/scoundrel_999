# Cooperative Scoundrel — working prototype

A physical cooperative card game inspired by **Scoundrel, by Zach Gage and Kurt Bieg**. Original wording for this experimental adaptation; no affiliation implied.

**Status:** concept-stage, playable paper prototype. All mechanics below are proposals for testing, not accepted design decisions. The user has selected **progression within a session**; nothing carries between sessions.

Start with [the canonical rules](docs/rules.md): two players, one ordinary deck, paper, and a pencil. Play **0.1.0-base** to examine cooperation alone, or **0.1.0-growth** to include one shared ability earned during the run. No custom cards, app, or dependencies are needed.

- [Design goals, assumptions, and source ambiguities](docs/design.md)
- [Rules history](docs/changelog.md)
- [Worked checks and first human playtest protocol](playtests/001-walkthrough.md)

Only constructed rules walkthroughs have been performed. No full games, balance batches, or human playtests have been completed; difficulty and duration are unknown.

Reference: [Scoundrel Vanilla](https://scoundrel-vanilla.netlify.app/). [Original 2011 rules, mirrored PDF](https://aiscoundrel.com/Scoundrel.pdf). This project does not reproduce original art.
