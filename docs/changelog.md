# Rules changelog

## 0.1.0 — 2026-10-25 — initial experimental prototype

- Created **0.1.0-base**, a two-player paper ruleset with individual health/equipment, alternating actions, targeted healing, and shared defeat. Purpose: test cooperation with ordinary playing cards.
- Set starting/max health to 12 per player as an explicitly untested balance parameter.
- Specified card ownership, replacement, strict weapon comparisons, potion waste, flee consent/order, terminal rooms, and immediate defeat so the prototype can be resolved consistently.
- Added **0.1.0-growth**, an optional one-time shared choice after four cleared rooms. Purpose: test the user's chosen within-session progression separately from core cooperation. No between-session persistence.
- Recorded reference inconsistencies and local interpretations; preserved attribution to Zach Gage and Kurt Bieg.
- Performed constructed walkthrough checks documented in playtests/001-walkthrough.md. No full games or balance estimates yet.
